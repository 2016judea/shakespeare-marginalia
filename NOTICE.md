# Data sources, licensing, and citation

This tool combines two separately-licensed data sources at **runtime** — it does not
bundle or redistribute either one. Every time you run it, it fetches fresh copies
from the source. Nothing from either project is checked into this repository.

## 1. Play text — Folger Shakespeare (Folger Shakespeare Library)

Fetched from `shakespeare.folger.edu`, licensed **CC BY-NC 4.0** (Attribution,
NonCommercial). That means:

- **Attribution required** — this repo credits Folger in every generated document's
  title page, and you should too if you reuse the output.
- **Non-commercial only.** Do not sell PDFs generated by this tool, and don't build a
  paid product on top of it. That restriction is inherited from Folger's license and
  is non-negotiable regardless of what this repo's own MIT license says about the code.

Citation: *The Folger Shakespeare*, ed. Barbara A. Mowat, Paul Werstine, Michael Poston,
and Rebecca Niles. Folger Shakespeare Library. https://shakespeare.folger.edu.

## 2. Marginalia data — Melville's Marginalia Online

Fetched from `melvillesmarginalia.org`, directed by Steven Olsen-Smith (Boise State,
founding editor) and Christopher Ohge (University of London, General Editor). This
project has **not declared an open license** for its XML transcription data. Their
stated policy (`/pages/policies`) covers two things:

- **Photographic page images are restricted to one-time display use** — reuse
  requires written consent from the holding institution (Houghton Library, Harvard).
  **This tool never touches page images** — it works only from the transcribed
  text/coordinate data in their public XML endpoint, and generates its own plain-text
  render of the marks (underline/score/checkmark/etc.) rather than reproducing any
  scan.
- **Citation is required**: author and title information, "Melville's Marginalia
  Online," the project's two main editors, and date of access. This repo's generated
  output includes that citation automatically.

Because no reuse license is declared for the XML data itself, **this tool fetches it
live on every run instead of bundling or redistributing it**, and asks the same of
anyone who uses it. If you build something substantial on top of this — especially
anything beyond a personal reading copy — reach out to the project first
(`monline@boisestate.edu`); they've been nothing but generous with making this
material public, and it costs nothing to ask.

Citation: Melville's Marginalia Online, ed. Steven Olsen-Smith and Christopher Ohge.
https://melvillesmarginalia.org. Original volumes held at the Houghton Library,
Harvard University (Sealts #460).
